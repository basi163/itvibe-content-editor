# IT Vibe Content Editor

Внутренний Telegram-редактор IT Vibe. Сервис следит за RSS Solidot, проверяет
первоисточники, отбирает важные технологические новости, переводит их на русский и
создаёт готовые черновики в редакторском канале.

## Что входит в MVP

- адаптивная проверка `https://www.solidot.org/index.rss`: каждые две минуты в
  активные часы публикаций и каждые 30 минут в остальное время;
- защита от повторной обработки одной новости;
- до трёх контролируемых попыток для материалов, которые не прошли формальную
  проверку текста, с локальным исправлением безопасных ошибок форматирования;
- чтение Solidot и связанных внешних источников;
- первичный отбор через Qwen Flash;
- отбор включает космические миссии, существенные изменения рынка устройств,
  значимые обновления массового ПО и подтверждённые исследования долголетия;
- написание поста через Qwen Plus;
- лимит 2000 видимых символов;
- автоматическая проверка стиля;
- сохранение точной безопасной причины ошибки вместо общего статуса `ValueError`;
- единый rich-пост со встроенным изображением и полным текстом;
- редакторские кнопки для заголовка, хэштегов, превью, загрузки медиа и перегенерации;
- публикация одобренного материала сразу, в следующее окно или в указанное время;
- приём пересланных постов из других Telegram-каналов;
- SQLite без отдельного сервера базы данных.

## Правила поста

- первая строка является жирным заголовком в обычном шрифте Telegram;
- абзацы всегда разделены одной пустой строкой;
- внутри текста нет другого жирного выделения;
- нет эмодзи и двоеточий;
- длинное тире используется редко;
- исключены шаблонные обороты из редакционной инструкции;
- добавляются ровно три хэштега;
- после хэштегов через пустую строку добавляется кликабельная подпись
  `🔳 IT Vibe News`;
- ссылки на первоисточники встроены в подходящие слова;
- Solidot и другие вторичные издания не выводятся как ссылки;
- изображение сначала берётся из исходных и связанных статей;
- если у статей нет картинки, Qwen ищет подходящую иллюстрацию по смыслу поста;
- выбранная картинка входит в то же Telegram-сообщение;
- материал отсеивается из-за картинки только если не сработали оба способа;
- все остальные ссылки доступны только через редакторскую кнопку `Источники`.

## Расписание RSS

По умолчанию сервис проверяет ленту каждые две минуты с 07:30 до 15:30 и с
18:00 до 22:30 по Самаре. В остальное время интервал составляет 30 минут. Перед
началом активного окна ожидание автоматически сокращается, поэтому первая
проверка не опаздывает из-за длинного ночного интервала.

Расписание настраивается через `RSS_ACTIVE_WINDOWS`, часовой пояс — через
`RSS_SCHEDULE_UTC_OFFSET_HOURS`, а интервалы — через
`RSS_POLL_INTERVAL_SECONDS` и `RSS_OFFPEAK_POLL_INTERVAL_SECONDS`.

## Отложенные публикации

После нажатия `Опубликовать` меню появляется прямо под постом
в редакционном канале и дублируется в личном чате с ботом. Можно
опубликовать сразу, выбрать следующее свободное окно или один из шести
ближайших временных слотов. По умолчанию окна
равны `09:00,12:00,15:00,18:00,21:00` по Самаре. Они настраиваются через
`PUBLISH_SCHEDULE_SLOTS` и `PUBLISH_SCHEDULE_UTC_OFFSET_HOURS`.

Для ручного времени можно прислать `18:30`, `сегодня 18:30`, `завтра 10:00`
или `25.10.2026 12:00`. Запланированный черновик можно опубликовать сразу,
перенести или снять с расписания. При временной ошибке Telegram бот делает до
трёх попыток с интервалом пять минут.

## Контент-план

Кнопка `Контент-план` под каждым редакционным постом и команда
`/plan` в боте показывают очередь с точным временем выхода. Из плана
можно перенести, снять с расписания или сразу опубликовать пост, а также
перегенерировать его заголовок, хэштеги, изображение или весь текст.

Активный канал итоговой публикации виден в контент-плане. Между ранее
добавленными каналами можно переключаться inline-кнопками. Новый канал выбирается
через системный Telegram-выбор в личном чате с ботом.

Для добавления нового канала:

1. добавить `@itvibe_editor_bot` администратором канала;
2. включить боту право публикации сообщений;
3. открыть «Канал публикации» в контент-плане и нажать «Добавить другой канал»;
4. в личном чате с ботом нажать «Выбрать канал публикации»;
5. выбрать канал в системном окне Telegram и дождаться подтверждения.

## Запуск на Ubuntu

Требования

- Ubuntu 22.04 или новее;
- Docker Engine с Compose plugin;
- Telegram-бот, добавленный администратором в редакторский канал;
- API-ключ Alibaba Cloud Model Studio.

Создать конфигурацию

```bash
cp .env.example .env
chmod 600 .env
```

Заполнить минимум два значения

```dotenv
TELEGRAM_BOT_TOKEN=replace_me
QWEN_API_KEY=replace_me
```

Скопировать `LLM_BASE_URL` из рабочего пространства Model Studio. Ключи и адреса
Singapore, US Virginia и China Beijing не взаимозаменяемы.

Запустить сервис

```bash
docker build --target test .
docker compose up -d --build
docker compose logs -f --tail=100
```

Первый человек, который отправит `/start` после чистого запуска, становится владельцем
бота. Поэтому сразу после запуска нужно открыть личный диалог с ботом и выполнить
`/start`, затем `/setup`.

Команда `/setup` позволяет выбрать два канала

1. Редакторский канал для черновиков.
2. Канал для окончательной публикации.

Бот должен заранее быть администратором обоих каналов с правами публиковать, изменять и
удалять собственные сообщения.

## Обновление

```bash
git pull --ff-only
docker compose up -d --build
```

## Секреты

Файл `.env` исключён из Git. Не добавляйте токены в исходный код, Dockerfile,
`docker-compose.yml`, историю Git или логи. После замены Telegram-токена обновите
`TELEGRAM_BOT_TOKEN` и перезапустите контейнер.

## Локальная проверка

```bash
python -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
pytest
ruff check .
```
