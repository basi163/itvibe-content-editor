# IT Vibe Content Editor

Внутренний Telegram-редактор IT Vibe. Сервис следит за RSS Solidot, проверяет
первоисточники, отбирает важные технологические новости, переводит их на русский и
создаёт готовые черновики в редакторском канале.

## Что входит в MVP

- адаптивная проверка `https://www.solidot.org/index.rss`: каждые пять минут в
  активные часы публикаций и каждые 30 минут в остальное время;
- защита от повторной обработки одной новости;
- до трёх контролируемых попыток для материалов, которые не прошли формальную
  проверку текста, с локальным исправлением безопасных ошибок форматирования;
- чтение Solidot и связанных внешних источников;
- первичный отбор через Qwen Flash;
- отбор включает космические миссии, существенные изменения рынка устройств,
  значимые обновления массового ПО и подтверждённые исследования долголетия;
- написание поста через Qwen Plus;
- лимит 2000 видимых символов;
- автоматическая проверка стиля;
- сохранение точной безопасной причины ошибки вместо общего статуса `ValueError`;
- единый rich-пост со встроенным изображением и полным текстом;
- редакторские кнопки для заголовка, хэштегов, превью, загрузки медиа и перегенерации;
- публикация одобренного материала сразу, в следующее окно или в указанное время;
- публикация в Telegram-каналы и Teletype-блоги с
  отдельным расписанием для каждой площадки;
- приём пересланных постов из других Telegram-каналов;
- мониторинг новых постов в открытых Telegram-каналах через их
  публичную веб-ленту;
- автоматическое удаление из SQLite обычных неопубликованных черновиков старше
  30 дней без удаления сообщений из Telegram;
- SQLite без отдельного сервера базы данных.

## Правила поста

- первая строка является жирным заголовком в обычном шрифте Telegram;
- абзацы всегда разделены одной пустой строкой;
- внутри текста нет другого жирного выделения;
- нет эмодзи и двоеточий;
- длинное тире используется редко;
- исключены шаблонные обороты из редакционной инструкции;
- добавляются ровно три хэштега;
- после хэштегов через пустую строку добавляется кликабельная подпись
  `🔳 IT Vibe News`;
- ссылки на первоисточники встроены в подходящие слова;
- Solidot и другие вторичные издания не выводятся как ссылки;
- изображение сначала берётся из исходных и связанных статей;
- если у статей нет картинки, Qwen ищет подходящую иллюстрацию по смыслу поста;
- выбранная картинка входит в то же Telegram-сообщение;
- материал отсеивается из-за картинки только если не сработали оба способа;
- все остальные ссылки доступны только через редакторскую кнопку `Источники`.

## Ручная подача в редакцию

Любой новый текст или пересланный пост, который редактор отправляет прямо
в редакционный канал или группу, запускает принудительную подготовку черновика.
Бот сразу показывает статус приёма и убирает его после доставки готового черновика.
Qwen независимо проверяет утверждения через веб-поиск, а найденные страницы и
поисковые фрагменты проходят отдельную проверку по содержанию. Неподтверждённые
утверждения передаются в карточку как неопределённости, а не как факты.

Тематический фильтр для такой подачи не отклоняет материал. После фактчека он
переписывается, получает изображение, три хэштега, подпись и обычные редакторские
кнопки. Сообщения интерфейса и уже созданные черновики повторно не захватываются.

## Расписание RSS

По умолчанию сервис проверяет все включённые RSS- и Telegram-источники каждые пять
минут с 05:00 до 23:00 по Самаре. В остальное время интервал составляет 30 минут. Перед
началом активного окна ожидание автоматически сокращается, поэтому первая
проверка не опаздывает из-за длинного ночного интервала.

Расписание настраивается через `RSS_ACTIVE_WINDOWS`, часовой пояс — через
`RSS_SCHEDULE_UTC_OFFSET_HOURS`, а интервалы — через
`RSS_POLL_INTERVAL_SECONDS` и `RSS_OFFPEAK_POLL_INTERVAL_SECONDS`.

## RSS и публичные Telegram-источники

В главном меню редакционного канала есть кнопка `Источники контента`.
Через неё можно подключить публичную RSS/Atom-ссылку, `@username`
или ссылку `https://t.me/username`. Любой источник можно временно выключить,
удалить или запустить его внеочередную проверку. Встроенный Solidot RSS можно
выключить, но нельзя удалить. Меню дублируется командой `/sources` в личном боте.

Меню текстом показывает, какие RSS-ленты и Telegram-каналы подключены.
Кнопка `Проверить все сейчас` выдаёт отдельные статистику и список
подключённых источников для RSS и Telegram.

При подключении бот сохраняет текущие записи RSS или последний видимый
ID Telegram как точку отсчёта, поэтому старая история не импортируется. Новые материалы
проходят общие отбор, переписывание, подбор изображения и дедупликацию.

Сборные Telegram-посты с тремя или более нумерованными новостями и ссылками
автоматически распознаются как дайджесты. Каждый пункт кратко переписывается на русском,
а его исходная ссылка встраивается в слова. Порядок пунктов и соответствие ссылок сохраняются.

Для каждого дайджеста автоматически собирается фирменная обложка IT Vibe. Номер выпуска,
до шести главных тем и лейблы компаний берутся из самого материала. Цветовая схема, фон и
одна из четырёх поз маскота выбираются по преобладающей теме: ИИ, гаджеты, кибербезопасность
или технологический бизнес. Картинки источников используются как затемнённый фон, а весь
текст накладывается программно, поэтому названия не искажаются генеративной моделью.
Кнопка `Другое изображение` создаёт ещё один вариант обложки с другой позой.

Используется только открытый HTML, который Telegram отдаёт без входа. Авторизации,
куки, MTProto, закрытые каналы и обход ограничений не используются.

## Хранение черновиков

Обычный неопубликованный черновик удаляется из серверной SQLite-базы через 30 дней
после создания. Запланированные материалы и черновики, имеющие успешную публикацию
хотя бы в одном канале, не удаляются. Сообщения в редакционном и других Telegram-каналах
очистка не изменяет и не удаляет.

Срок задаётся через `UNPUBLISHED_RETENTION_DAYS`, а период запуска фоновой очистки —
через `DRAFT_CLEANUP_INTERVAL_SECONDS`. По умолчанию очистка запускается сразу при
старте контейнера, затем один раз в сутки.

## Отложенные публикации

После нажатия `Опубликовать` меню появляется прямо под постом
в редакционном канале и дублируется в личном чате с ботом. Можно
опубликовать сразу, выбрать следующее свободное окно или один из шести
ближайших временных слотов. По умолчанию окна
равны `09:00,12:00,15:00,18:00,21:00` по Самаре. Они настраиваются через
`PUBLISH_SCHEDULE_SLOTS` и `PUBLISH_SCHEDULE_UTC_OFFSET_HOURS`.

Для ручного времени можно прислать `18:30`, `сегодня 18:30`, `завтра 10:00`
или `25.10.2026 12:00`. Запланированный черновик можно опубликовать сразу,
перенести или снять с расписания. При временной ошибке Telegram бот делает до
трёх попыток с интервалом пять минут.

## Контент-план

Кнопка `Контент-план` под каждым редакционным постом и команда
`/plan` в боте показывают очередь с точным временем выхода. Из плана
можно перенести, снять с расписания или сразу опубликовать пост, а также
перегенерировать его заголовок, хэштеги, изображение или весь текст.

Активная площадка итоговой публикации видна в контент-плане. Между ранее
добавленными Telegram-каналами и Teletype-блогами можно переключаться
inline-кнопками. У каждой площадки собственные дни и время публикации.

Для добавления нового канала:

1. добавить `@itvibe_editor_bot` администратором канала;
2. включить боту право публикации сообщений;
3. открыть «Канал публикации» в контент-плане и нажать «Добавить другой канал»;
4. в личном чате с ботом нажать «Выбрать канал публикации»;
5. выбрать канал в системном окне Telegram и дождаться подтверждения.

### Добавление Teletype-блога

Бот создаёт в Teletype полноценную статью: заголовок, обложку, абзацы,
кликабельные ссылки на первоисточники, три хэштега и ссылку `IT Vibe News`.
Токен аккаунта Teletype хранится только в серверном `.env` и никогда не
отправляется в Telegram или Git.

1. в Terminal на сервере запустить `scripts/set_teletype_token.sh` и ввести токен скрыто;
2. перезапустить сервис `editor`;
3. в редакционном канале открыть `Контент-план` → `Канал публикации` →
   `Добавить канал` → `Teletype-блог`;
4. отправить ссылку `https://teletype.in/@itvibe` и дождаться проверки прав;
5. включить Teletype в списке каналов и задать для него расписание.

Если `TELETYPE_ACCESS_TOKEN` не задан, Telegram-публикации работают как прежде, а меню
Teletype показывает инструкцию по настройке. Изображение загружается в Teletype; при
временном сбое загрузки для публичной картинки используется исходная ссылка.

### Кросспостинг Teletype → VK

Кросспостинг работает как отдельная очередь: успешная публикация статьи в
Teletype не отменяется при ошибке VK. Для VK выполняются до четырёх попыток;
после окончательного сбоя бот сообщает об ошибке в редакционный канал.

1. создать в настройках сообщества VK ключ с правом «Стена»;
2. на сервере запустить `scripts/set_vk_token.sh`, ввести ID сообщества и ключ;
3. перезапустить сервис `editor`;
4. в редакционном канале открыть `Главное меню` → `Кросспостинг из Teletype`;
5. отправить боту публичную ссылку сообщества и дождаться проверки.

Ключ VK никогда не передаётся через Telegram и не хранится в SQLite. В редакционном
меню можно включать и выключать VK, сменить целевое сообщество и повторить ошибочные задачи.

## Запуск на Ubuntu

Требования

- Ubuntu 22.04 или новее;
- Docker Engine с Compose plugin;
- Telegram-бот, добавленный администратором в редакторский канал;
- API-ключ Alibaba Cloud Model Studio.
- для публикации в Teletype — токен аккаунта с доступом к нужному блогу.
- для кросспостинга в VK — ключ сообщества с правом «Стена».

Создать конфигурацию

```bash
cp .env.example .env
chmod 600 .env
```

Заполнить минимум два значения

```dotenv
TELEGRAM_BOT_TOKEN=replace_me
QWEN_API_KEY=replace_me
# Необязательно: только если нужна публикация в Teletype.
TELETYPE_ACCESS_TOKEN=replace_me
TELETYPE_CLIENT_VERSION=4.41.26
# Необязательно: только если нужен кросспостинг Teletype -> VK.
VK_COMMUNITY_ACCESS_TOKEN=replace_me
VK_COMMUNITY_GROUP_ID=123456789
VK_API_VERSION=5.199
# Публикация обложки через обычный веб-редактор VK.
VK_BROWSER_WEBDRIVER_URL=http://vk-browser:4444/wd/hub
VK_BROWSER_TIMEOUT_SECONDS=45
```

Для первичного входа в VK открыть защищённый SSH-туннель:

```bash
ssh -L 7900:127.0.0.1:7900 root@SERVER_IP
```

Затем открыть `http://localhost:7900`, войти в VK как
администратор сообщества и закрыть вкладку. Профиль Chromium
хранится в Docker volume и не публикуется в сеть.

Скопировать `LLM_BASE_URL` из рабочего пространства Model Studio. Ключи и адреса
Singapore, US Virginia и China Beijing не взаимозаменяемы.

Запустить сервис

```bash
docker build --target test .
docker compose up -d --build
docker compose logs -f --tail=100
```

Первый человек, который отправит `/start` после чистого запуска, становится владельцем
бота. Поэтому сразу после запуска нужно открыть личный диалог с ботом и выполнить
`/start`, затем `/setup`.

Команда `/setup` позволяет выбрать два канала

1. Редакторский канал для черновиков.
2. Канал для окончательной публикации.

Бот должен заранее быть администратором обоих каналов с правами публиковать, изменять и
удалять собственные сообщения.

## Обновление

```bash
git pull --ff-only
docker compose up -d --build
```

## Секреты

Файл `.env` исключён из Git. Не добавляйте токены в исходный код, Dockerfile,
`docker-compose.yml`, историю Git или логи. После замены Telegram-токена обновите
`TELEGRAM_BOT_TOKEN` и перезапустите контейнер.

## Локальная проверка

```bash
python -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
pytest

```
